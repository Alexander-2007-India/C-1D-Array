# C 1D Array

A beginner-level C program that demonstrates how to take 5 marks from the user and store and display them using a 1D array.

## Concepts Used

* 1D Arrays
* `for` loop
* `scanf()`
* `printf()`
* Array indexing

## Example

```text
Enter 5 marks: 92 85 76 88 95

  92  85  76  88  95
```

This is one of my practice programs while learning C programming.
